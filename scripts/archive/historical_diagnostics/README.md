# Historical Diagnostic Scripts

This directory preserves 21 diagnostic scripts developed
during the investigation of DT-based multi-AGV navigation.

## Investigation Areas

- Digital Twin position inference.
- Reachable-position coverage.
- Command execution uncertainty.
- AGV motion and movement blockers.
- Estimated and robust progress.
- Medoid-based position estimation.
- Safety-aware action selection.
- Waiting and stagnation behavior.
- M7 episode horizon sensitivity.

## Preservation Status

All 21 Python scripts passed syntax validation before
archiving.

The scripts are preserved as historical research artifacts.

Their runtime compatibility with the final DICR
implementation has not been established.

Some scripts depend on historical evaluation interfaces,
internal controller methods and pretrained checkpoints.

Some scripts use runtime patching or write experimental
output files.

They should not be executed against preserved research
results without reviewing their configuration.

The final evaluation and Step 13 diagnostic scripts
remain outside this archive.

No historical diagnostic algorithms were modified
during archiving.
